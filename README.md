# Grey Edition

Tampermonkey dark themes by **expDARE**, hosted in [ExtraPotions/super-octo-parakeet](https://github.com/ExtraPotions/super-octo-parakeet).

## Install

| Script | Install |
| --- | --- |
| **ManaPool Grey Edition** | [raw install](https://raw.githubusercontent.com/ExtraPotions/super-octo-parakeet/main/manapool-grey-edition.user.js) |
| **Scryfall Grey Edition** | [raw install](https://raw.githubusercontent.com/ExtraPotions/super-octo-parakeet/main/scryfall-grey-edition.user.js) |
| **SteamGifts Grey Edition** | [raw install](https://raw.githubusercontent.com/ExtraPotions/super-octo-parakeet/main/steamgifts-grey-edition.user.js) |

Tampermonkey checks `@updateURL` on these raw files for updates.

## Versions

Release line starts at **1.5.0**. Currently published:

- ManaPool Grey Edition `1.5.2`
- Scryfall Grey Edition `1.5.0`
- SteamGifts Grey Edition `1.5.0` (ESGST-compatible; derived from [SG Dark Grey](https://github.com/SquishedPotatoe/SG-Dark-Grey) by SquishedPotatoe, CC-BY-SA-4.0)

## Notes

- **SteamGifts Grey Edition** also matches SteamTrades and SGTools (same as the upstream theme). It is CSS-only and designed to coexist with [ESGST / A-ESGST](https://github.com/JustArchi/ESGST).
